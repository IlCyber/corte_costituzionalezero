# Casellario digitale della Corte Costituzionale di Zero

Applicazione statica demo con dati persistenti nel browser tramite `localStorage`.

## Funzioni principali

- Archivio documenti e template con editor ricco, numerazione e stampa PDF.
- Sezioni separate per Partiti e Aziende, con documenti Statuto/Regolamento e storico delle versioni.
- Sezione Parlamento con mandati, legislazione, date, tag In corso/Concluso, titolari e sostituti configurabili.
- Informazioni parlamentari personalizzabili nelle Impostazioni: ogni nomina conserva giuramento, dimissioni, partito, coalizione e campi aggiuntivi.
- Dimissioni registrate senza cancellare il parlamentare dallo storico e nuova nomina disponibile come azione.

Credenziali demo: `admin` / `zero2026`.

Per l’uso reale su Altervista serviranno backend PHP/MySQL, autenticazione server e controllo degli accessi.
